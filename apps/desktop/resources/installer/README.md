# Release artwork

`icon.svg` is the original source mark for Nolira Build. It does not reuse the 1Code name, logo, or other trademark assets.

The checked-in platform exports are `icon.icns` for macOS, `icon.ico` for Windows, and a 1024×1024 `icon.png` for Linux. Regenerate all three from `icon.svg` when the source mark changes.

Do not replace these files with upstream 1Code brand artwork.
