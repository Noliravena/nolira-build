# Nolira Build

Grok-first desktop coding workspace monorepo.

## Structure

```
apps/          # Applications (to be developed)
packages/      # Shared packages
```

## Setup

```bash
pnpm install
```

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `pnpm build`   | Build all packages/apps  |
| `pnpm dev`     | Start dev tasks          |
| `pnpm lint`    | Lint                     |
| `pnpm test`    | Test                     |
| `pnpm format`  | Format with Prettier     |
| `pnpm clean`   | Clean build artifacts    |
